# ТВ-петля «Моя Церква»

Анімації для телевізора на конференції: сцена за сценою, по колу, без звуку.
Це веб-сторінка — відкрили в Chrome на весь екран (F), і вона крутиться сама.
Той самий файл кладеться на сайт як `/tv/`, а за потреби пишеться в MP4.

```
python3 brand/tv/build.py assets              # іконки lucide, словесний знак, QR → src/icons.js, src/brand.js
python3 brand/tv/build.py html                # out/tv.html — один файл, працює без інтернету
python3 brand/tv/build.py site                # public/tv/index.html → mychurch.com.ua/tv/ (noindex)
python3 brand/tv/build.py frames people --o land,port --count 12   # аркуш кадрів для перевірки
python3 brand/tv/build.py frames people --at 1200,3400,6000        # конкретні миті
python3 brand/tv/build.py video --o land      # out/video/*.mp4 (повільно, лише коли треба відео)
python3 brand/tv/build.py video --o land --list main    # основна добірка
```

Живий перегляд: `python3 -m http.server 3420 --directory brand/tv/out` → `http://localhost:3420/tv.html`.
`?scene=people` — крутити одну сцену, `?only=intro,people,outro` — добірка, без параметрів грає основна
добірка `main` з `order.js`, `?list=all` — усі сцени (стара адреса `?list=short` = main), `?o=port` — портрет.
Клавіші: ← → сцени, пробіл — пауза, F — на весь екран, O — альбом/портрет.

## Файли

- `src/tv.css` — токени, полотно, типографіка, примітиви руху. **Спільне — сцени його не правлять.**
- `src/lib.js` — `TV.*`: обличчя, курсори, іконки, словесний знак, криві. **Спільне.**
- `src/tv.js` — плеєр і режим запису. **Спільне.**
- `src/order.js` — порядок сцен. **Спільне.**
- `src/scenes/<id>.js` — одна сцена = один файл. Id = id модуля з каталогу (`src/lib/i18n.ts` → `modules.groups`).
- Еталон: `src/scenes/ministries.js` (Служіння). Нову сцену пишемо як він.

## Контракт сцени

```js
// icons: calendar, check, clock          ← кожна іконка lucide, яку сцена кличе через змінну
(function () {
  TV.scene({
    id: "people",            // = id модуля
    dur: 8000,               // мс; 7000–9000. Останні 520 мс плеєр сам гасить сцену.
    bg: "light",             // "light" | "blue" | "dark"
    css: `[data-scene="people"] .mock { … }`,   // КОЖЕН селектор починається з [data-scene="<id>"]
    html: (o) => `…`,        // o = "land" (1920×1080) | "port" (1080×1920)
    tick(t, el, o) { … },    // необов'язково: чиста функція від t (мс) — лічильники, курсори
  });
})();
```

**Час.** Уся анімація — CSS keyframes, що стартують у мить появи сцени, з затримкою `--d`
(мс від старту). Так петля грає плавно, а запис може поставити будь-яку мить.
Звідси правила, які ламають запис, якщо їх порушити:
- жодних `transition` і жодних `setTimeout`/`setInterval`/`requestAnimationFrame` у сцені;
- `tick()` лише змінює `textContent`, `style.*` або атрибути; **не додає елементів і класів**
  (новий клас = нова анімація, що стартує не вчасно);
- будь-яка зміна стану «до → після» — це два шари: старий зникає `a-outf`/`a-out`,
  новий з'являється `a-fade`/`a-pop` з тією самою `--d`. Приклад — галочки й закреслення в `ministries.js`;
- keyframes з затримкою завжди `both`; якщо елемент має бути невидимим до своєї миті,
  перший кадр keyframes має `opacity: 0` (інакше `both` покаже його на старті — див. конфеті).

Примітиви в `tv.css` (затримка — `style="--d:1200ms"`):
`a-up a-down a-left a-right a-fade a-pop a-scale a-rise` — поява; `a-out a-outf` — зникнення.
Криві: `var(--e-emph)` (основна), `var(--e-decel)` (поява), `var(--e-accel)` (зникнення), `var(--e-spring)` (пружина для дрібниць).

**Розкладка.** `TV.copy({ title, line, accent })` + `.vis > .mock` у `.split` (як в еталоні).
`.mock` має фіксований розмір у пікселях полотна і масштаб `--vs` (альбом) / `--vs-port` (портрет).
Альбом: місце під екран праворуч ≈ 920×1000. Портрет: ≈ 900 завширшки, ≈ 1150 заввишки під текстом.
Можна `.split.flip` (екран ліворуч) — чергуйте, щоб сусідні сцени не були однакові.
Довга назва сама зменшить кегль, щоб вміститись у колонку.

**Шрифт у макеті — від 20 px**, заголовки карток 26–30 px: це читають з 3–5 метрів.

## Правила бренду (з відгуків власника — порушення = переробка)

1. **Показуємо продукт, а не рекламу.** Заголовок = назва модуля (1–3 слова), одне речення =
   рядок з каталогу `modules.groups[*].items[*].text` дослівно. Жодних абзаців, булітів, «переваг».
2. **Екран — картинка, а не список.** Рядки «іконка + текст + бейдж» у рамці відхилені. Шукайте
   власну геометрію модуля: календарна сітка, план залу, стрічка тижнів, карта людей, канбан,
   телефон, квиток, QR… Один екран несе кілька фактів одразу.
3. **Екран оживає сам**: щось відбувається — людина ставить галочку, заявка їде по колонках,
   лічильник росте, бот відповідає. Курсор людини — `TV.cursor(ім'я, колір, id)` +
   `TV.moveCursor(...)` у `tick` + `TV.tap(...)` у html: великий, кольоровий, з обличчям.
   Один курсор ніколи не перетворюється на іншу людину; двох курсорів одночасно не буває.
4. **Мальовані обличчя** — лише `TV.avatar(ім'я, розмір)`. Жодних фото людей, стоку, емодзі-облич.
5. **Лише українська.** Жодного англійського слова в тексті (назви сервісів Telegram/Viber — можна).
6. **Ніякого «безкоштовно», «спробувати», «trial», цін.** Дія, якщо треба, — «Запланувати зустріч».
7. **Кнопки пласкі**: суцільний колір, без градієнтів і відблисків.
8. **Телефон** — прямо, пропорції справжнього iPhone (≈ 390×844, радіус ≈ 56), без 3D-нахилу.
9. **Не вигадуйте факти**: імена, дати, назви, числа беріть з `src/content/modules/<група>.ts`
   (`copy.ua.mock`, `features`, `pipeline`, `benefits`) і з демо на сайті. Вигадані люди
   вигаданої церкви — так, як на сайті (Андрій, Олена, Оксана, Марко…).
10. Не більше трьох панелей у кадрі; повітря важливіше за кількість.

Колір модуля — `MODULE_ACCENTS` у `src/components/shared/module-icons.ts`.

## Перевірка

Після кожної правки: `python3 brand/tv/build.py assets` (якщо додали іконку), потім
`python3 brand/tv/build.py frames <id> --o land,port` і **дивимось аркуш** `out/frames/<id>-land.png`
та `-port.png`: нічого не вилазить за полотно, текст не налазить, кадр 0 порожній (крім тла),
останній кадр — сцена вже згасає. Консольні помилки друкуються після шляху до аркуша.
